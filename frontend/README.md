# Notes App — Frontend

React + TypeScript + Vite frontend for the Notes App, with Tailwind CSS.

## Setup

1. Install dependencies:

```bash
   npm install
```

2. Copy the example env file and set your backend URL:

```bash
   cp .env.example .env
```

Update `VITE_API_URL` in `.env` to point to your running backend .

3. Start the dev server:

```bash
   npm run dev
```
