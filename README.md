# Notes App

A production-ready Notes Application built during the 10Pearls Shine MERN Internship.

## Tech Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- Node.js
- Express
- TypeScript
- PostgreSQL (Planned)

### Code Quality
- ESLint
- Prettier
- GitHub Actions
- CodeRabbit
- SonarQube (Planned)

## Project Structure

```
.
├── backend/
├── frontend/
├── docs/
└── .github/
```

## Development

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
